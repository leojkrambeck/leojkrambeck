## 🚀 Projeto em destaque

### Alimentador Automático de Cães – Visão Computacional + Sistemas Embarcados
Sistema que reconhece cada animal por imagem e libera a ração certa para ele.

- Modelo de classificação de imagens treinado em **TensorFlow Lite**, com dataset anotado no RoboFlow
- Inferência embarcada em uma **ESP32-S3-CAM**, integrada a uma **ESP32** que controla o compartimento e a porção
- Cerca de **93% de acerto** nos testes com três perfis de animais
